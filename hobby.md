# Наш пет-проект

Идея: простой список учебных задач. Можно будет добавить задачу, посмотреть список и отметить выполненное.

Стек: Python. Задачи буду хранить в JSON-файле.

Цель: научиться работать с файлами и сделать небольшую программу, которой можно пользоваться самому.

В первой версии будет три действия: добавить задачу, вывести список и отметить задачу выполненной. Управление пока сделаю через терминал.
