# Git в IntelliJ IDEA

Вместо VS Code использую IntelliJ IDEA.

Что удобно:
1. В окне Commit видны изменённые файлы. Можно сразу сравнить старую и новую версии.
2. В истории Git видны коммиты и ветки. Не нужно каждый раз вводить git log.
3. Через Annotate можно посмотреть, кто и в каком коммите изменил строку.

В терминале мне удобнее создать ветку и сразу переключиться на неё: git switch -c имя-ветки.
