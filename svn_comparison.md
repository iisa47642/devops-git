# Git и SVN

1. Почему ветки в Git называют дешёвыми?

Ветка в Git — это ссылка на коммит. Она создаётся локально и не копирует все файлы.
В SVN ветка — отдельный каталог в репозитории. На сервере такая копия тоже создаётся быстро и не дублирует сразу все данные. Поэтому называть ветки SVN дорогими по размеру не совсем правильно. Главное отличие — зависимость от центрального репозитория.

2. Можно ли сделать коммит в SVN без интернета?

Нужен доступ к репозиторию. Если сервер находится в интернете и связи нет, коммит не получится. Если репозиторий доступен по локальной сети или находится на этом же компьютере, интернет не нужен. В Git коммиты сохраняются локально, а на сервер отправляются позже.

3. Когда SVN может быть удобнее?

Когда проект уже использует SVN и переход не нужен. Ещё SVN подходит, если нужны отдельные права на каталоги или блокировка файлов, которые сложно объединять, например чертежей и других двоичных файлов.
